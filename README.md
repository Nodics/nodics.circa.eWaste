# Circa eWaste

Circa eWaste is a Nodics customer experience for submitting verified electronic waste, receiving sustainability appreciation rewards, managing carbon-backed circular assets, trading those assets, and buying enterprise coupons using reward wallet balance.

The first implementation uses local demo adapters so the complete journey can be visually tested before live backend operation contracts are wired.

## Current Journey

- Public corporate page explaining Circa.
- Header login and just-in-time login/register inside the Submit eWaste helper.
- Location check with nearby collection centres and map handoff.
- Photo upload/camera capture and AI-style metadata summary.
- Submission under approval.
- Customer dashboard with assets, filters, wallet summary, and asset detail actions.
- Tradeable asset marketplace.
- Enterprise coupon marketplace.

## Domain Ownership

- Waste owns submission, evidence, approval, asset lifecycle, and carbon-linked asset facts.
- Loyalty/Wallet owns reward and carbon ledger balances.
- Commerce/Promotion owns coupons, coupon purchases, issued entitlements, and POS claim.
- Location owns centre search and map display.
